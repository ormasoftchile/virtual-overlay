For redistributors
-----------------

Keep all license and notice files with the DLLs. Make this source-access file
available alongside each installer/portable download, without requiring an
installation to read it. GPLv3 section 6(d) allows corresponding source on
another server when recipients are given clear directions and equivalent
access. Maintain availability of the matching source for as long as you offer
the binaries; archive/mirror the listed source if these URLs stop working.
Do not substitute a generic GCC home page for the matching source archives.
No new written source offer on behalf of Virtual Overlay is made by this file.
